# Ece Akdeniz

MSc Computer Science student at the University of Stuttgart, interested in robotics, perception, state estimation, and applied AI.

I build systems that connect sensor data and machine learning with inspectable results, from robot incident analysis and Bayesian tracking to AI negotiation agents.

## Selected projects

- **[y/trace](https://github.com/ece-akdeniz/yTrace)** — Robot incident replay and analysis using KUKA telemetry and OpenTSLM. Built with team y/agent; second place at the Zurich Temporal AI Challenge.
- **[3D LiDAR Odometry](https://github.com/ece-akdeniz/3D-LiDAR-Odometry)** — C++ and ROS 2 odometry using robust ICP and an Eigen-only core.
- **[Multi-Camera Visual Tracking](https://github.com/ece-akdeniz/Multi-Camera-Visual-Tracking)** — Bayesian quadcopter tracking with KF, EKF, UKF, and camera self-calibration.
- **[Multimodal Gaze Forecasting in VR](https://github.com/ece-akdeniz/Multimodal-Gaze-Forecasting-in-VR)** — Gaze prediction from head motion and spatial audio, evaluated on D-SAV360.
- **[harve/y](https://github.com/ece-akdeniz/harve-y)** — AI buyer agent for the Tacto Negotiation Arena, built for the European Hackathon League finals.
- **[Qats — GHZ States](https://github.com/ece-akdeniz/Qiskit-Fall-Fest-2026)** — Team experiments in GHZ-state preparation and certification on IBM quantum hardware.
